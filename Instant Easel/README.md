# Instant Easel

A standalone drawing app: brushes, layers, colour wheel, shapes, text, mirror drawing, undo/redo, crash recovery.

- **Run from source:** `pip install -r requirements.txt` then `python main.py`
- **Windows app:** `EXE Build/InstantEasel.exe` (GitHub rebuilds it automatically whenever the code changes)
- **Folder guide:** [docs/FOLDERS.md](docs/FOLDERS.md)
